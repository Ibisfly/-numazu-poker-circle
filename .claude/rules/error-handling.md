## エラー境界

- ユーザー向けエラー（フォームバリデーション・残高不足など）は UI にメッセージを表示する
- `catch (e: unknown)` で受け取り、`e instanceof Error ? e.message : 'エラーが発生しました'` で安全にメッセージを取り出す
- システムエラー（Firestore 失敗など）はユーザーに「もう一度お試しください」と表示し、詳細はコンソールに出力する

## 操作中の UX

- 非同期操作中は `loading` ステートでボタンを `disabled` にする
- 操作完了後にフォームをリセットし、成功・失敗メッセージを表示する

## 禁止事項

- `console.error` のみでユーザーに何も表示しない実装
- エラー時に画面が固まったまま操作不能になる実装
- `catch` ブロックを空にする（`// ignore` 等）

## 二重付与・重複操作の防止

- 来店スキャンは `attendances` の `eventId+uid` 複合クエリで二重付与を検証してから書き込む
- コスメティックアイテムは購入前に `userItems` で所持確認を行う
